Design notes (not part of the chart itself):
· All amounts here are made up for layout purposes — the real version reads straight from your 618 imported transactions.
· The range pills + custom dates filter every chart and stat tile on the page to that window — changing them re-renders everything below, same single-source-of-truth pattern as the Expenses table's own filters.
· The Expense trend chart's Day/Week/Month toggle is local to that one chart (same per-chart customization pattern as Progress Tracker's chart-type switcher) — Day draws a true daily line (every single day, not bucketed), Week/Month re-aggregate into bars at that granularity.
· "Balance over time" stays a single series (your own brand teal) — no legend needed, the title names it.
· "Income vs. expense" is the one 2-series chart here — teal (income) vs. a warm red (expense), checked against this app's own dark card background with the project's palette validator: passes colorblind-separation (ΔE 11.1) and contrast; a legend is shown since there are 2 series.
· Top-merchants uses one hue throughout — color-per-merchant would be noise for a simple magnitude ranking, so it stays one consistent color with direct value labels instead.
· Every chart here becomes a real Recharts component in the actual build (already a dependency, same library Progress Tracker's charts use) — this is hand-drawn SVG only to settle layout/interaction before writing real code.
